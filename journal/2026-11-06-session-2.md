# Lab Journal: 2026-11-06 (Session 2)

**Time spent:** ~2 hours
**Phase:** 0, Plan and baseline (hardware decided)

## Goal for this session
Finalize hardware, set up the GitHub repo, and understand the tools before starting the build.

## What I did
- Published the repo structure: README, journal template, .gitignore, and folders for configs, rules, reports, tickets, scripts and screenshots
- Learned what each tool does in my pipeline:
  - Cowrie: honeypot that records attacker logins and commands
  - Suricata: IDS that watches network traffic to and from the Pi
  - Sigma: universal rule format for log detections; converts to KQL, SPL and others
- Learned why custom rules matter: built-in SIEM rules are generic, so I write rules for gaps found in my own honeypot data
- Confirmed hardware:
  - Raspberry Pi 5, 8 GB RAM: runs Cowrie and Suricata
  - Storage: SanDisk High Endurance 128 GB microSD ($36.99)
  - Laptop (Ryzen 7 7730U, 16 GB RAM, 364 GB free): runs Wazuh in an Ubuntu VM on VirtualBox
- Chose Wazuh over EveBox because it is closer to real SOC tools
- Decided against a managed switch and port mirroring: honeypot traffic already reaches the Pi; whole-home monitoring is a possible later upgrade
- Compared storage options: SSD is better for 24/7 logging, but official kits are out of stock. Rejected a no-name SSD (unknown endurance and Pi 5 compatibility) and a non-endurance microSD. Logs also go to Wazuh, so data is safe if the card fails. Will clone to an SSD when back in stock.

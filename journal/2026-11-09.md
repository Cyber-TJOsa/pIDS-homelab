# Lab Journal: 2026-11-09

**Time spent:** ~2.75 hours
**Phase:** 1 (Pi setup) and 3 (SIEM)

## Goal for this session
Install the Wazuh SIEM and set up the Raspberry Pi OS.

## What I did
- Installed Wazuh 4.14 all-in-one in the VirtualBox VM (Ubuntu 26.04); switched the VM to Bridged networking
- Installed Raspberry Pi OS Lite (64-bit) on the Pi using Network Install (no SD card reader needed); wiped the pre-installed card for a known-good baseline; hostname pids-sensor; wired Ethernet, no Wi-Fi
- Enabled SSH on the Pi and connected from my laptop; ran a full system update
- Moved the SIEM from VirtualBox to WSL2 (Ubuntu 24.04, mirrored networking, 8 GB RAM / 4 CPUs); reinstalled Wazuh 4.14.10 in about 20 minutes, and the dashboard now runs at full speed

## What broke and how I fixed it
- VirtualBox ran too slowly because of my laptop's built-in Windows security settings, which caused the VM to freeze. Fix: switched to WSL2, which runs at full speed on my laptop.

# Lab Journal: 2026-11-07

**Time spent:** ~1.5 hours
**Phase:** 3, Logging and dashboard (started early while waiting on the microSD)

## Goal for this session
Build the laptop VM that will run the Wazuh SIEM.

## What I did
- Installed VirtualBox 7.2.22 on my laptop (skipped the Extension Pack, not needed)
- Created VM "wazuh-siem": 4 CPUs, 8 GB RAM, 80 GB dynamically allocated disk
- Installed Ubuntu Server 26.04.1 LTS with OpenSSH server; skipped Ubuntu Pro and snaps
- Used NAT networking because I was not on my own network; will switch to Bridged at home so the Pi can reach the VM
- Installed system updates
- Confirmed Wazuh 4.14 runs on Ubuntu 26.04 (installer shows a warning but works)

## What broke and how I fixed it
- Installer looked frozen: closing the capture pop-up kept keyboard input from reaching the VM, and the text installer doesn't use the mouse. Fix: clicked inside the VM and used the keyboard.
- "Soft lockup" warning during install: the VM was briefly starved of CPU time; install finished fine.
- Forgot my VM username; GRUB recovery menu was hard to catch. Recovered it.
- Ubuntu only allocated 38 GB of the 80 GB disk (LVM default). Fix: `lvextend --extents +100%FREE` and `resize2fs`; now 77 GB.
- VM runs in slow mode (turtle icon) because Windows Hyper-V/Memory Integrity holds the CPU's virtualization. Not fixed yet; fix planned before installing Wazuh (trade-off: Memory Integrity is a Windows security feature).
